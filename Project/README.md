## 🔍 Overview

This project explores the **strategic relationship between product placement and sales performance** in a retail environment. By leveraging **Tableau's visualization capabilities**, this analysis uncovers how positioning, promotions, pricing strategies, and consumer demographics interact to drive or hinder revenue outcomes.

The end goal is to empower business stakeholders and product managers with **actionable, data-backed insights** — enabling smarter shelf strategies, promotional decisions, and inventory planning.

---

## 🎯 Objectives

- 📦 Analyze how **product positioning** influences purchase behavior
- 💰 Understand the impact of **pricing strategies** on sales volume
- 📣 Evaluate the effectiveness of **promotional campaigns**
- 🌿 Detect **seasonal trends** that affect product performance
- 👥 Segment findings by **consumer demographics**
- 📊 Present findings through **interactive Tableau dashboards**

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  Data Collection │ → │  Data Cleaning &  │ → │ Exploratory Data │
│  & Preparation  │    │  Preprocessing    │    │   Analysis (EDA) │

                                                        │
                                                        ▼
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
```

1. **Data Collection** — Gathered retail sales data including product metadata, placement locations, promotional records, and customer demographics
2. **Data Cleaning** — Handled missing values, standardized formats, and removed duplicates
3. **EDA** — Explored distributions, correlations, and patterns across product categories and placement zones
4. **Tableau Visualization** — Built interactive dashboards segmented by category, time, region, and promotion type
5. **Insight Generation** — Derived strategic recommendations from visual patterns

## 🚀 How to Use

### Prerequisites
- [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Public](https://public.tableau.com/) (free)

### Steps

```bash
# 1. Clone this repository
git clone https://github.com/TanyaVaish-17/Strategic-Product-Placement-Analysis-Unveiling-Sales-Impact-with-Tableau-Visualization.git

# 2. Navigate to the project folder
cd Strategic-Product-Placement-Analysis-Unveiling-Sales-Impact-with-Tableau-Visualization
```

3. Open the `.twbx` (Tableau Workbook) file in **Tableau Desktop** or **Tableau Public**
4. Explore the dashboards interactively — filter by region, category, time period, and more
5. Review the insights panel for strategic recommendations

## 📈 Results & Findings

- **Product placement location** is a statistically significant driver of sales variance across categories
- **Promotional effectiveness** varies widely by segment — Consumer segment responds better to discounts vs. Corporate
- **Seasonal patterns** are most pronounced in Q4, with up to **3x sales spikes** in select categories
- **Technology products** suffer the greatest margin erosion from discounting strategies
- Recommendations include optimizing end-cap allocations for high-margin SKUs and revising discount thresholds for the Technology category
